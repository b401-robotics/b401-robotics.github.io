## Priority Issues

### [P1] Broken Navigation Freedom: Aggressive Section Reload Redirect
- **What:** In `src/pages/LandingPage.tsx` (lines 34–37), browser reload while viewing deep-linked section route (`/research`, `/equipment`, `/practicums`) forcefully redirects user back to `/`.
- **Why it matters:** Breaks standard web navigation and Nielsen Heuristic #3 (User Control & Freedom). Users lose current reading context on refresh.
- **Fix:** Remove `isReload` redirect guard in `LandingPage.tsx`; preserve requested URL path.
- **Suggested command:** `/impeccable harden`

### [P2] Inert Contact Form with Zero Feedback
- **What:** `ContactSection.tsx` form submit calls `e.preventDefault()` with no input validation, loading indicator, or confirmation message.
- **Why it matters:** Violates Heuristic #1 (Visibility of System Status) and #5 (Error Prevention). External collaborators cannot tell if inquiry sent or failed.
- **Fix:** Implement form validation, submission state with feedback banner or modal confirmation receipt.
- **Suggested command:** `/impeccable harden`

### [P3] Trapped Viewport Heights & Nested Scrollbars
- **What:** `ResearchSection.tsx` and `EquipmentSection.tsx` enforce fixed viewport constraints (`md:max-h-[calc(100vh-4.75rem)]`) with internal scroll containers (`md:overflow-y-auto`).
- **Why it matters:** Dual-scrollbar collision on standard laptop screens. Scrolling mouse captures inside inner element before window scrolls.
- **Fix:** Allow sections to flow naturally using standard vertical padding (`py-16 md:py-24`).
- **Suggested command:** `/impeccable layout`

### [P3] Sparse "About" Section Content Architecture
- **What:** `AboutSection.tsx` occupies full screen height but only renders heading and large logo with 2 lines of text.
- **Why it matters:** Stalls user scroll momentum early in homepage journey; misses opportunity to communicate research pillars or lab metrics.
- **Fix:** Add 3-column stats or focus metric strip (testbed rooms, championships, core research domains).
- **Suggested command:** `/impeccable clarify`
