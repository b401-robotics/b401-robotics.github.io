# Notable Work & Projects
A showcase of student and faculty projects spanning robotics, AI, and embedded systems.

### Autonomous Line Following Robot [Status: Completed]
A self navigating robot using PID control and infrared sensors for precise line tracking on complex tracks.
Technologies: Embedded C, PID Control, Sensor Fusion

### Robotic Arm with Vision Guidance [Status: Active]
A 6-DOF robotic arm that uses computer vision to identify and pick objects from a conveyor belt autonomously.
Technologies: ROS 2, OpenCV, Python, Inverse Kinematics

### Smart Home Automation System [Status: Active]
IoT based smart home system with voice recognition, energy monitoring, and mobile app integration.
Technologies: ESP32, MQTT, React Native, TensorFlow Lite

### Drone Formation Flight [Status: Research]
Multi UAV coordination system enabling synchronized formation flight using distributed control algorithms.
Technologies: PX4, MAVLink, Formation Control

### Human Activity Recognition [Status: Completed]
Deep learning model for realtime human activity recognition using IMU sensor data from wearable devices.
Technologies: PyTorch, LSTM, IMU Sensors

### Gesture Controlled Wheelchair [Status: Active]
Assistive technology project enabling wheelchair control through hand gesture recognition using a depth camera.
Technologies: MediaPipe, RealSense, ROS 2

### Bipedal Walking Robot [Status: Research]
A humanoid robot lower body designed to study dynamic walking and balance using zero moment point control.
Technologies: ROS, C++, Simscape

### LoRaWAN Environmental Monitor [Status: Completed]
Distributed wireless sensor network for large scale agricultural monitoring using low power wide area networks.
Technologies: ESP32, LoRa, InfluxDB
